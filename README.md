# NovaShop

## Descripción

NovaShop es la planeación de un sistema de gestión de comercio electrónico orientado a pequeñas tiendas. El sistema permitirá administrar usuarios, productos, categorías, inventario, carritos de compras y pedidos.

## Problema identificado

Muchos pequeños negocios administran sus productos y pedidos mediante hojas de cálculo, mensajes y registros separados. Esto puede provocar errores de inventario, duplicación de información y pérdida de pedidos.

## Objetivo general

Planificar un sistema web de gestión de e-commerce que permita administrar usuarios, productos, inventario, carritos y pedidos de manera organizada, segura y fácil de utilizar.

## Módulos principales

- Usuarios y seguridad
- Catálogo de productos
- Categorías
- Inventario
- Carrito de compras
- Pedidos
- Pagos simulados
- Reportes

## Tecnologías propuestas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Node.js
- Express
- MySQL
